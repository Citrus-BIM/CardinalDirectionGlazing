# Устойчивый расчёт остекления по сторонам света

## Цель

Исключить потерю площади окон на границах направлений и при ненадёжном геометрическом запасном поиске помещения.

## Решение

Классификатор направлений после проверки ненулевой проекции в XY всегда возвращает ближайшее из восьми направлений. Порог совпадения `cos(22,5°)` не применяется: ближайшее направление определено для любого ненулевого вектора, а границы секторов разрешаются детерминированно максимальным скалярным произведением.

Основным источником стороны окна остаются две spatial calculation points Revit. Это штатные точки, которыми Revit определяет помещения/пространства с двух сторон семейства. Если их нет либо они не дают ровно одну точку внутри целевого помещения, запасной механизм проверяет несколько пробных точек по нормали окна с обеих сторон через `Room.IsPointInRoom` или `Space.IsPointInSpace`. Луч по `Solid` остаётся последним совместимым резервом.

Окно не включается, если точка снаружи принадлежит другому помещению/пространству: это межкомнатное окно, а не наружное остекление целевого помещения.

## Проверки

Автоматические регрессионные тесты фиксируют оба угла из обращения (21,29° у юга и 21,36° у запада), точные границы 22,5° и отсутствие отказа на валидных ненулевых направлениях.
